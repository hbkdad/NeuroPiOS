# hbkdad/neuropios

This repository hosts two independent projects:

## NeuroPiOS

An AI-first operating system experience for Raspberry Pi (local LLM shell, live monitoring, terminal-native control). The marketing/landing page is `index.html`; release artifacts are tracked under `releases/`.

## AION — Adaptive Intelligence Optimization Network

A decentralized AI compute, model, agent, and intelligence marketplace, in early research/specification/simulation stages. Start here:

- `docs/ARCHITECTURE.md` — system design
- `docs/ROADMAP.md` — phase-by-phase status (what's actually built vs. specified vs. planned)
- `docs/research/` — competitor analysis, technology research, capability matrix
- `docs/adr/` — architecture decision records
- `simulations/poig_sim/` — the only part of AION with working, tested code so far (an economic simulator for the PoIG reward mechanism)

See `AGENTS.md` for contributor/agent rules specific to the AION subtree, and `CONTRIBUTING.md` / `SECURITY.md` for both projects.
